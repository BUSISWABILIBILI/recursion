# Recursion

A JavaScript recursion project built for The Odin Project. This project includes Fibonacci sequence generation and the Merge Sort algorithm.

## Features

- Iterative Fibonacci function
- Recursive Fibonacci function
- Recursive Merge Sort algorithm
- Command-line testing using Node.js

## Built With

- JavaScript
- Node.js

## Run the Project

Run Fibonacci:

```bash
node fibs.js
```
